# 🎬 TeraBox Video Downloader Bot

A Telegram bot that downloads videos from public TeraBox links and sends them directly to your chat.

## Features
- Paste any public TeraBox link and get the video instantly
- Files under 50 MB are sent directly in Telegram
- Files over 50 MB get a direct download button
- Supports all TeraBox domains (terabox.com, teraboxapp.com, 1024terabox.com, etc.)

## Usage
1. Start the bot on Telegram
2. Send any public TeraBox share link
3. Get your video!

## Commands
- `/start` — Welcome message
- `/help` — How to use the bot

## Deployment
Deployed on Railway with Python 3.11.
